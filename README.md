# irregular-voice-google

Research project: irregular voice with Google.

## Setup

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

## Usage

```bash
uv run python -c "import irregular_voice_google"
```

## Tests

```bash
uv run pytest
```

## Layout

```
src/irregular_voice_google/   # package source
tests/                        # pytest tests
```
