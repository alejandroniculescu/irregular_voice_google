# Personal Voice Control for atypical speech using LoRA

Project page: https://alejandroniculescu.github.io/irregular_voice_google/

A personal Whisper adapter (LoRA) for one German speaker with dysarthria: 55.4 % word error rate for the base
German Whisper model on his speech, 13.2 % with the adapter, 10.7 % with a phonetic word-repair step, on 39
held-out clips. Model: https://huggingface.co/alejandroniculescu/whisper-large-v3-turbo-german-lora-20260923-182243-q5_0.bin
